# ContractIQ - AI Contract Intelligence

ContractIQ is a full-stack Next.js application designed to automate the analysis, parsing, and semantic querying of legal contracts (PDF & DOCX). It provides a ChatGPT-like interface directly integrated with document text, complete with structural clause analysis and smart citation verification.

## Features

- **Smart Document Parsing:** Extracts text from PDF and DOCX files automatically on upload.
- **AI Contract Assistant:** Chat with your contract using the Vercel AI SDK. It will semantically search the document to answer your legal queries.
- **Citation Verification:** Every answer generated by the AI includes inline clickable citations that highlight the exact source quote in the document viewer.
- **Contract Comparison:** Compare two versions of a contract (Original vs Revised) to automatically identify and classify added, removed, or modified clauses by severity (High, Medium, Low).
- **Beautiful UI:** Built with Tailwind CSS, shadcn/ui, and Radix Primitives for a modern, responsive, and accessible user experience.

## Technology Stack

- **Framework:** Next.js 14+ (App Router, Server Actions)
- **Language:** TypeScript
- **Database:** PostgreSQL (via Prisma ORM)
- **AI & LLM:** Vercel AI SDK with OpenAI `gpt-4o-mini`
- **Styling:** Tailwind CSS, shadcn/ui
- **Parsing:** `pdf-parse` (PDF) and `mammoth` (DOCX)
- **Icons:** `lucide-react`

## Getting Started

### Prerequisites
- Node.js (v20+)
- PostgreSQL Database
- OpenAI API Key

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/DeepGoyani/ContractIq.git
   cd ContractIq
   ```

2. **Install dependencies:**
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Configure Environment Variables:**
   Create a `.env` file in the root directory and add your keys:
   ```env
   DATABASE_URL="postgresql://user:password@localhost:5432/contractiq?schema=public"
   OPENAI_API_KEY="sk-your-openai-api-key"
   ```

4. **Initialize the Database:**
   ```bash
   npx prisma generate
   npx prisma db push
   ```

5. **Start the Development Server:**
   ```bash
   npm run dev
   ```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the result.

## Architecture

1. **Documents Pipeline:** 
   Uploaded files are immediately passed to an edge extraction pipeline that converts binaries to raw text. The text is semantically chunked into token-limited blocks and stored in PostgreSQL with Postgres' built-in `tsvector` full-text search indexing.
2. **Retrieval-Augmented Generation (RAG):**
   The AI Assistant is powered by a multi-tool agent loop. It uses `search_document` to query the PostgreSQL chunk database and returns grounded answers.
3. **Difference Engine:**
   Contract comparisons use LLM-driven structured generation to evaluate paragraph-by-paragraph diffs, outputting a precise JSON object of semantic changes.
